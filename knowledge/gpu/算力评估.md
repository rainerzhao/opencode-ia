# 算力需求评估

## 计算公式

```
所需 GPU 卡数 = (模型参数量 × 每参数字节数 × 并发数) / 单卡显存
```

## 示例计算

**场景：部署 7B 参数模型，支持 50 QPS 并发**

1. 模型大小：7B × 2 bytes (FP16) = 14GB
2. 显存需求：14GB × 50 (并发) = 700GB
3. 单卡 A100 显存：80GB
4. 所需卡数：700 / 80 ≈ 9 张

**优化方案：**
- 使用 INT8 量化：14GB × 0.5 = 7GB → 7 × 50 / 80 ≈ 5 张
- 使用 KV Cache 复用：进一步降低显存需求
