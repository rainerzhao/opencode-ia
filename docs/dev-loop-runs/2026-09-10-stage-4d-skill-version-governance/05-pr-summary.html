Mac 验收完成 · Stage 4D

团队 Skill 中心已经具备版本治理

成员可以把已经发布的 Skill 继续演进为默认私有的新版本草稿；当前团队版本不会被草稿影响。通过校验后，成员可自主升级或回滚自己的安装版本，并必须重新经 OpenCode 验证才会启用。

这次交付了什么

  • 不可变发布版本与保留历史版本
  • 按账号的升级、回滚和重新验证
  • 原子包替换与失败补偿
  • 创建者/admin 的停用与归档治理
  • 常驻 Runtime 下基于 Skill 集合重绑工作区/Session，避免旧 Skill 缓存继续生效
  • 面向产品的版本选择与治理界面

已验证

  • 真实 OpenCode 1.18.25：升级发现 0.2.0，回滚发现 0.1.0
  • 另一个成员不能发现该 Skill；停用后新受管工作区也不能发现
  • 桌面和手机宽度无页面横向溢出、无浏览器错误

这是 Mac 上的应用级验收，不代表 Linux 生产上线。Linux 服务账号、进程级沙箱、内部模型接入、监控、备份和长期容量仍属于 Stage 5。
