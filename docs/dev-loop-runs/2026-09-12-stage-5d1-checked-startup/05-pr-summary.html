Stage 5D1：受检生产启动

应用与部署契约通过，目标镜像构建待网络恢复

目标

Docker 与 systemd 在开放端口前强制检查 MySQL-only、非 root、Secure Cookie、OpenCode Runtime 和 Provider 配置。

生产拓扑

Compose 只运行工作台，使用受保护的连接串访问公司云 MySQL；数据库实例、高可用、自动备份和基础监控不由应用容器承担。

验证

定向测试 11/11；真实 MySQL 全量 355 项、350 通过、0 失败、5 项真实 OpenCode 可选验收跳过；构建、175 个 JavaScript 语法检查和密钥扫描通过。

安全边界

两项门禁使用同一服务账号 UID；Provider 配置须为 0600 且归该账号所有；Docker build context 排除本机配置、数据库、日志、Git 和交接材料。

剩余边界

目标基础镜像仍被本机 Docker mirror 403 阻断。本阶段不替代公司 Linux 真机、云数据库网络/TLS 和内部 Provider 验收。
