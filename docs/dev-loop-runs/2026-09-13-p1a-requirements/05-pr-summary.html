解决的问题

交付内容

  • 管理员维护统一 BU 目录；成员创建、更新、筛选、分页和归档自己的需求。

  • SQLite 与 MySQL v10 迁移；生产 MySQL 组合使用同一需求仓储。
  • 管理员不能凭角色读取成员私人需求正文；跨账号读取、修改和搜索均为 404/空结果。
