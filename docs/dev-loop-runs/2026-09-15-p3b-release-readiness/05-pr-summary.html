P3B · LOCAL FOUNDATION

预发布就绪报告

把两项已有生产门禁收敛为一份可保存、脱敏、机器可读的交接证据。

一个入口

`npm run preflight:release` 同时运行生产配置与 OpenCode Provider 门禁。

安全输出

只输出状态、错误代码、MySQL 类别、Cookie / 非 root 布尔值与 Provider 数量。

失败即阻止

任一门禁失败仍保留脱敏报告，但进程返回非零退出码。

不改变启动器

生产启动仍使用原有强制门禁；该报告没有启动 HTTP 或访问公司资源。

未关闭 P3B：公司 Linux、云 MySQL、内部模型、真实 20 用户、故障恢复和灾备仍必须在预发布机获得独立证据。
