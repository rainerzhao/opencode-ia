Stage 4C：团队 Skill 发布、安装与发现

将已校验的私有 Skill 变成可人工发布、按成员独立安装并经 OpenCode 验证后启用的团队资产。

用户可见变化

创建者在校验通过后确认发布；团队成员在目录中依次安装、启用。启用仅影响当前账号，随后该 Skill 才会出现在该账号的 Conversation 工作区。

关键保护

  • 发布绑定当前内容摘要、静态报告与 Runtime 通过证据。
  • 每账号受管安装目录，0700/0600 权限、manifest、摘要复核与原子替换。
  • 路径逃逸、链接、摘要漂移、数据库失败和 Runtime 验证失败全部关闭门禁。
  • 审计不记录 Skill 正文、附件或 Provider 信息。
