MySQL 测试隔离验收

本变更让真实 MySQL 回归可以重复执行：迁移、账号引导与审计数据不再跨用例残留；Worker 的异常退出验收也不再依赖机器负载时序。

范围

  • 仅测试夹具和测试用例，不改变产品业务行为。
  • 重置操作仅接受回环地址且库名包含 test 的明确测试连接。
  • 未包含正在开发的 MySQL Skill Store 与 Stage 3C 文档。

验收

真实 MySQL 全量：300 通过、0 失败；默认无密钥：291 通过、0 失败。

构建、JavaScript 语法检查与密钥扫描均通过。此结论仅适用于 Mac/Docker 开发验收，不代表 Linux 生产上线。
