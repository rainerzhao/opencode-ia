恢复语义
  • 运行任务必须中断，不静默重放。
  • 排队任务只允许保留 marker 完成，或在 recovery boundary 后中断。
  • 重启后通过账号登录和 HTTP API 读取持久历史，不依赖旧进程内存。
安全边界
  • 不自动清空远端数据库。
  • 不输出 PID、Prompt、回复、Cookie、数据库 URL、密钥或配置路径。
  • Harness 就绪不等于公司生产灾备验收完成。
